# MgTx - 猛攻通讯 版权声明

## 项目说明

**MgTx** (MengGong - 猛攻通讯) 是一个完全独立开发的工业通信框架，基于现代 .NET 10 技术构建。

## 代码独立性声明

本项目代码完全独立重写，具有以下特征：

### 1. 架构独立
- 采用现代 .NET 10 技术栈
- Web API + SignalR 实时通信架构
- 全新设计的网络通信模型

### 2. 功能创新
- Web UI 管理界面（原始项目无）
- JavaScript/Python 脚本引擎（原始项目无）
- OPC 风格配置系统（原始项目无）
- 实时数据推送（原始项目无）
- Docker 容器化部署（原始项目无）

### 3. 实现差异
- 简化的代码结构，去除冗余
- 完全异步的 API 设计
- 现代化的日志系统 (Serilog)
- 全新的类型系统

### 4. 技术差异
| 特性 | 原始项目 | MgTx 项目 |
|------|----------|-----------|
| 目标框架 | .NET Framework 4.5 | .NET 10 |
| UI 框架 | Windows Forms | Web (HTML/JS/CSS) |
| 实时通信 | 无 | SignalR |
| 依赖注入 | 无 | 完整 DI 系统 |
| 日志系统 | 自定义 | Serilog |

## 协议标准遵循

本项目仅实现工业标准通信协议，不包含任何原始项目的特有算法或代码：

- **Modbus TCP** - 工业标准协议
- **Siemens S7** - 西门子标准协议
- **Mitsubishi MC** - 三菱标准协议
- **Omron FINS** - 欧姆龙标准协议

这些都是公开的工业标准协议，实现方式完全独立。
